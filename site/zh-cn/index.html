邮件 · 日历 · 任务

在本地统一处理多个账号的邮件、日历和任务

Corresync 把工作和个人账号的邮件、日历和任务接入 Codex、Claude Code、其他 MCP 智能体和终端。各账号分开登录和授权，查找、安排、跟进和执行都用同一组工具。

支持的服务：Outlook · Gmail · Google 日历 · Microsoft To Do · Todoist · TickTick · 开放标准。每个账号的连接方式和功能都会单独列出。查看服务详情。

隐私政策使用条款

安装之后

添加账号并开始使用

Corresync 不预选服务商。它先不用凭据查找这个地址可用的连接方式，添加你选定的一种，之后才能登录该账号。

1 · 选择并登录

corr setup you@example.com --alias personal
corr auth login --account personal

查找时不打开任何页面。之后单独运行 login，用选定的方式登录。

2 · 连接

corr mcp setup codex

把本地 stdio 服务器注册到智能体中，然后重启一次客户端。

3 · 提问

› 汇总所有账号里今天中午前
  需要我处理的事情

智能体调用工具，回答会注明信息来自哪个账号。

使用示例

跨账号搜索邮件、查看日程、预览发送

CLI 和 MCP 使用同一组操作、账号隔离和策略检查。

同时搜索所有收件箱

“找一下季度计划那封邮件，我忘了在工作邮箱还是个人邮箱。” 

$ corr mail search --all-accounts \
    --query 'subject:"quarterly plan"'
● work · microsoft-owa  Ana Ruiz  Plan review
· personal · jmap   Finance      Plan receipt

某个账号失败时，结果会标为不完整，不会被悄悄省略。

查看合并后的日程

“我今天在两个日历上都有什么安排？”

$ corr agenda list --all-accounts \
    --start 2026-07-29T00:00:00Z \
    --end 2026-07-30T00:00:00Z
09:30 work      Design review · Teams
12:30 personal  Dentist

每个事件都带有时区、所属日历和服务商信息。

发送前预览邮件

“帮我起草给 Ana 的回复，发送前我自己确认。” 

› 起草给 Ana 的回复
  mail_send
REVIEW · send new message
  to    ana@example.invalid
  body  text/plain · 412 B
确认这份内容之前不会发送。

执行时的账号、收件人和内容必须与预览时逐字节一致。

安全机制

第一次调用不会直接发送

重要操作第一次调用只返回待确认内容。批准与调用方、账号、服务商、目标、内容和有效期绑定，只能使用一次。

  • 智能体只能调用工具，拿不到凭据。密码、Cookie 和 OAuth 授权不经过 MCP，配置文件里也没有对应的字段。
  • 只在本机运行。MCP 服务器在本机通过 stdio 通信。
  • 结果不确定时停止。远程写入结果不明确时不会自动重试。
  • 邮件内容按不可信数据处理。邮件里的内容不能触发命令，也不能启动智能体。

连接方式

优先使用开放标准，必要时使用服务商原生接口

邮件和日历的连接方式分开选择，所以同一个账号可以用 IMAP/SMTP 收发邮件，同时用 CalDAV 访问日历。

浏览器登录

Outlook Web

Outlook 登录在一个专用的可见浏览器窗口中完成，支持邮件和日历操作。

OAuth（需自行选择）

Microsoft Graph · 使用自有客户端的 Google

Microsoft Graph 使用你有权使用的公开客户端。Google 使用你自己的桌面 OAuth 客户端。

开放标准

JMAP、IMAP/SMTP、CalDAV

连接加密端点，凭据来自系统钥匙串或一个经你批准的凭据助手。

先了解详情再添加。 服务指南列出具体的登录方式、设置要求和随账号而异的功能。

已知限制

当前版本的限制

完整的功能、限制和验证范围见功能页面。

  • Gmail、Google 日历和 Google Tasks 使用你自己的 OAuth 客户端。 引导设置会在你登录前把桌面客户端凭据导入系统钥匙串。
  • Microsoft Graph 需要自备 OAuth 客户端。Corresync 不提供令牌中继服务。
  • Windows 上暂不支持桌面通知。队列模式和已批准的执行器模式仍可使用。
  • 功能按账号确定。 设置时显示该账号实际可用的连接方式和服务，不按邮箱品牌推测。
