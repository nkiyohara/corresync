快速开始

从安装到第一次查询：四个步骤

安装 corr，添加工作或个人账号，把本地 MCP 注册到智能体，然后提一个跨账号的问题。结果合并显示时，各账号仍分开登录和授权。Outlook Web 在浏览器中登录；API 和标准协议的授权保存在系统钥匙串；MCP 只通过本地 stdio 通信。

从第 1 步开始先检查支持情况
  1. 1

    安装 corr

    这一步只安装程序，不添加账号，也不登录。

    macOS · Linux

    curl -LsSf https://corresync.org/install.sh | sh

    为当前用户安装经过校验的 stable 版本。可先阅读脚本。

    Windows · PowerShell

    powershell -NoProfile -Command "irm https://corresync.org/install.ps1 | iex"

    无需管理员权限，只修改当前用户的 PATH。可先阅读脚本。

    其他安装方式

    升级和卸载由包管理器负责。

    Windows · WinGet

    winget install --id nkiyohara.Corresync --exact

    macOS · Linux · Homebrew

    brew install nkiyohara/corresync/corresync

    Windows · Scoop

    scoop bucket add corresync https://github.com/nkiyohara/scoop-corresync
scoop install corresync/corresync

    Linux 的 .deb、.rpm、.apk，直接下载包、校验和、Sigstore 来源证明和 Claude Desktop .mcpb 都在最新发布中。

    确认安装

    corr --version

    自动更新 · 为已有配置开启

    corr config set updates.auto_install true

    从 0.9.2 起，新配置默认开启经过签名校验的自动更新，已有设置不变；已有配置可用这条命令开启。MCP 调用和机器可读输出不会触发安装。关闭命令：corr config set updates.auto_install false。

  2. 2

    添加邮件和日历账号

    第一次只需运行一条命令。引导程序询问邮箱地址，不读取凭据就查找邮件和日历服务，说明可选的连接方式，并在添加账号前显示完整预览。

    登录和读取外部凭据都要在确认后单独选择。之后可检查连接或继续添加账号。corr settings使用同样的键盘流程；使用屏幕阅读器时可设置CORRESYNC_ACCESSIBLE=true，改为逐行提示；输入:cancel可以退出当前输入步骤。

    Outlook Web 在服务商提供的浏览器页面中登录。服务商支持、且你选择了对应连接方式或凭据存储位置时，也可以用 Microsoft Graph、JMAP、IMAP/SMTP 和 CalDAV。查找服务时不打开浏览器、不读取钥匙串，也不发起管理员同意流程。

    使用 iCloud？corr setup会识别@icloud.com、@me.com、@mac.com，以及具备完整且已验证服务记录的 iCloud 自定义域名，并同时配置邮件和日历。添加账号后，引导程序会说明 Apple 双重认证和 App 专用密码的要求。密码由操作系统凭据窗口直接接收，Corresync 拿不到。

    使用 Google？在你自己管理的 Google Cloud 项目中创建桌面 OAuth 客户端。引导设置会检查下载的 JSON，在你从浏览器登录前把凭据导入系统钥匙串。

    不发送完整地址即可检查 · 登录由谁负责

    引导设置 · 推荐

    corr setup

    引导程序先检查本地状态，可按需安装 Shell 补全，并从未完成的步骤继续。连接方式在保存前预览，登录是单独的一步。之后可勾选检测到的多个智能体，确认本地配置计划，再逐个应用并检查。

    高级用法或脚本设置

    corr setup you@example.com --alias personal
corr auth login --account personal
corr doctor --account personal

    这些命令无需交互，适合脚本和自动化。

    iCloud 邮件和日历 · 已支持

    引导预设添加两项服务，可共用一个经你确认的凭据引用，并显示最近一次认证状态，不读取邮件正文或日程内容。连接前请阅读 Apple 官方的App 专用密码说明。

    Gmail · Google 日历 · Google Tasks

    按Google OAuth 图解指南操作，只启用需要的 API。客户端凭据和账号授权保存在本机钥匙串中。

  3. 3

    连接智能体

    命令把本地 stdio MCP 服务器的绝对路径写入客户端配置，不创建远程端点。完成后重启客户端。

    Codex

    corr mcp setup codex

    Claude Code

    corr mcp setup claude-code

    GitHub Copilot CLI

    corr mcp setup github-copilot

    Gemini CLI

    corr mcp setup gemini-cli

    Qwen Code

    corr mcp setup qwen-code

    Qoder

    corr mcp setup qoder

    Kimi Code CLI

    corr mcp config kimi-code

    任意 MCP 客户端

    corr mcp serve
  4. 4

    查询所有账号

    读取可以跨账号，但账号之间不混用。写入要先预览，再单独确认。

    • “在所有账号里找 Ana 发来的季度计划邮件。”
    • “明天上午所有日历里有什么安排？”
    • “起草给 Ana 的回复，发送前让我确认。”

    结果注明账号和服务商；某个连接失败时标为部分失败。发送时，只有账号、收件人和内容与预览逐字节一致，才能通过 CLI 的 --approve 或 MCP 的提交工具执行。批准有时效，且只能用一次。
