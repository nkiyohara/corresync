快速开始

从安装到第一次回答，清晰的四个步骤。

安装 corr，添加工作或个人账号，把本地 MCP 注册到智能体，然后提出跨账号问题。即使结果合并展示，每个账号的身份和授权仍然隔离。Outlook Web 登录由浏览器管理；API 和标准协议的 授权 留在系统钥匙串；MCP 只通过本地 stdio 通信。

从第 1 步开始先检查支持情况
  1. 1

    安装 corr

    这里只安装程序，不添加账号，也不会登录。

    macOS · Linux

    curl -LsSf https://corresync.org/install.sh | sh

    为当前用户安装已验证的 stable 版本。运行前可阅读脚本。

    Windows · PowerShell

    powershell -NoProfile -Command "irm https://corresync.org/install.ps1 | iex"

    无需管理员权限，只更新当前用户的 PATH。可先阅读脚本。

    其他安装方式

    交给包管理器管理升级与卸载。

    Windows · WinGet

    winget install --id nkiyohara.Corresync --exact

    macOS · Linux · Homebrew

    brew install nkiyohara/corresync/corresync

    Windows · Scoop

    scoop bucket add corresync https://github.com/nkiyohara/scoop-corresync
scoop install corresync/corresync

    Linux 的 .deb、.rpm、.apk，直接下载包、校验和、Sigstore 来源证明和 Claude Desktop .mcpb 都在最新发布中。

    验证

    corr --version

    可选 · 自动更新独立安装版

    corr config set updates.auto_install true

    只自动安装已签名并验证的独立安装版；MCP 调用或机器可读输出期间不会更新。

  2. 2

    设置邮件与日历账号

    第一次只需运行一条命令。引导程序会询问邮箱地址，在不读取凭据的前提下查找邮件和日历服务，说明可选路径，并在添加账号前显示完整预览。

    登录或读取外部凭据始终是确认之后的独立选择。随后还可以检查连接或继续添加其他账号。corr settings使用同一套键盘友好流程；屏幕阅读器用户可设置CORRESYNC_ACCESSIBLE=true，改用逐行提示；输入:cancel即可安全退出当前输入步骤。

    Outlook Web 使用由服务商掌控的浏览器登录。Microsoft Graph、JMAP、IMAP/SMTP 和 CalDAV 也可在服务商支持且你明确选择相应路径或凭据存储位置时使用。发现过程不会打开浏览器、读取钥匙串，也不会发起管理员同意流程。

    使用 iCloud？corr setup会识别@icloud.com、@me.com、@mac.com，以及具备完整且已验证服务记录的 iCloud 自定义域名，并一次配置邮件与日历。添加账号后，引导程序会说明 Apple 双重认证和 App 专用密码要求。密码由操作系统凭据界面直接接收，不会经过 Corresync。

    使用 Google？Gmail、Calendar 和 Tasks API 代码已在 RC 中，但生产环境 OAuth 等待审批，因此路径完全关闭，Google 登录无法启动。暂时请使用 Google 官方 Workspace MCP。

    不发送完整地址即可检查 · 了解登录归属

    引导设置 · 推荐

    corr setup

    引导程序先检查当前本地状态，可按需安装 Shell 补全，并从尚未完成的步骤继续。账号路径会在保存前预览，登录仍是独立操作；随后可多选已检测到的智能体，统一确认本地集成计划，再逐个应用和验证。

    高级用法或脚本设置

    corr setup you@example.com --alias personal
corr auth login --account personal
corr doctor --account personal

    原有命令仍保持非交互行为，适合脚本和自动化。

    iCloud 邮件与日历 · 现已支持

    引导预设会添加两项服务，可共用一个经过确认的凭据引用，并在不读取邮件正文或日程内容的情况下显示最近一次认证状态。连接前请阅读 Apple 官方的App 专用密码说明。

    Google · 审批前的临时方式

    参阅 Google 官方Workspace MCP 设置指南。该服务目前是 Developer Preview。

  3. 3

    连接你常用的智能体

    命令会把本地 stdio MCP 的绝对路径写入客户端自己的配置，不创建远程端点。之后重启客户端。

    Codex

    corr mcp setup codex

    Claude Code

    corr mcp setup claude-code

    GitHub Copilot CLI

    corr mcp setup github-copilot

    Gemini CLI

    corr mcp setup gemini-cli

    Qwen Code

    corr mcp setup qwen-code

    Qoder

    corr mcp setup qoder

    Kimi Code CLI

    corr mcp config kimi-code

    任意 MCP 客户端

    corr mcp serve
  4. 4

    跨所有账号提问

    读取可以跨账号但不会合并身份；写入则先审阅，再单独提交。

    • “在所有账号里找 Ana 发来的季度计划邮件。”
    • “明天上午所有日历里有什么安排？”
    • “起草给 Ana 的回复，发送前让我确认。”

    结果保留账号和提供商；失败路径显示为部分失败。发送时，只有与审阅过的账号、收件人和字节完全一致的内容才能通过 CLI --approve 或 MCP 提交 工具提交。批准短时且单次有效。
