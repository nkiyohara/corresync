尚未上架

尚未上架

目前可用 corr setup 完成经过审查的直接 MCP 配置；原生元数据和上游审核就绪后才会提交。

本地就是本地

目录上架不会自动启用云端代理或私有隧道。

Corresync 只提供本地 stdio 服务和本地账户状态。即使存在插件格式，托管版 ChatGPT、云端代理、Kiro Web 和远程沙箱也无法直接访问。

托管中继或私有 MCP 隧道会形成新的数据路径，必须另行完成架构决策、明确同意、隐私披露、撤销设计和安全审查。
