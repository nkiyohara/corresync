Mail · Calendar · Tasks

A local CLI and MCP server for mail, calendars, and tasks

Corresync connects your work and personal mail, calendars, and task lists to Codex, Claude Code, other MCP agents, and your terminal. Each account signs in on its own, and the same commands work across all of them.

Supported services: Outlook · Gmail · Google Calendar · Microsoft To Do · Todoist · TickTick · open standards. What works depends on the account and how it connects. See the provider details.

Set up with your AI agent Check my email provider

Sign-in happens in your browser or uses credentials kept in your OS keyring. Agents never get the credentials Corresync manages, and there is no hosted relay. Before sending mail or making another important change, Corresync shows an exact preview and waits for your approval.

After installing

Add an account and connect your agent

Corresync doesn’t assume a provider. It first looks up how your address can be reached, adds the account with the route you pick, and only then lets you sign in.

1 · Add an account and sign in

corr setup you@example.com --alias personal
corr auth login --account personal

The lookup opens nothing and signs nothing in. Login is a separate command and uses the route you picked.

2 · Connect your agent

corr mcp setup codex

Adds Corresync to your agent as a local stdio server. Restart the agent afterwards.

3 · Ask

› What needs my attention
  before noon, across all
  my accounts?

The agent calls Corresync’s tools, and each answer says which account it came from.

Examples

What you can ask for

The CLI and the MCP tools run the same operations with the same checks, so each example works from either one.

Search all inboxes

“Find the quarterly-plan thread. It’s in work or personal, I don’t remember which.” 

$ corr mail search --all-accounts \
    --query 'subject:"quarterly plan"'
● work · microsoft-owa  Ana Ruiz  Plan review
· personal · jmap   Finance      Plan receipt

If one account fails, the result says so and is marked as partial.

One agenda for all calendars

“What does my day look like across both calendars?”

$ corr agenda list --all-accounts \
    --start 2026-07-29T00:00:00Z \
    --end 2026-07-30T00:00:00Z
09:30 work      Design review · Teams
12:30 personal  Dentist

Each event shows its time zone, its calendar, and the provider it came from.

Check a message before it is sent

“Draft the reply to Ana. I’ll approve the send myself.”

› Draft a reply to Ana.
  mail_send
REVIEW · send new message
  to    ana@example.invalid
  body  text/plain · 412 B
Nothing sent until this exact
payload is approved.

The message is sent only if the account, recipients, and content match the preview exactly.

How sending works

The first command only shows a preview

A command that sends or changes something important first returns a review. The approval only works for that caller, account, provider, target, and content, expires, and works once.

  • Agents get tools, not credentials. No MCP tool exposes passwords, cookies, or OAuth grants, and the configuration file has no field for them.
  • Runs on your computer. The MCP server talks to your agent over stdio. There is no hosted relay, remote endpoint, or telemetry pipeline.
  • Unclear results are not retried. If Corresync can’t tell whether a remote write went through, it stops and does not retry on its own.
  • Mail content is treated as untrusted. Text in a message can’t make Corresync run a command or start an agent.

How accounts connect

Provider APIs, browser sign-in, and open standards

Mail and calendar routes are chosen separately. One account can use IMAP/SMTP for mail and CalDAV for its calendar, or one provider route for both.

Browser sign-in

Outlook Web

You sign in to Outlook yourself in a separate, visible browser window. Mail and calendar commands then work through that session.

OAuth

Microsoft Graph · Google with your own client

Microsoft Graph accepts a public client you are authorized to use. Gmail, Google Calendar, and Google Tasks use a Desktop client from a Google Cloud project you control.

Open standards

JMAP, IMAP/SMTP, and CalDAV

Connects over an encrypted connection. The password comes from an OS keyring entry or from a credential helper you approved.

Check before you add an account. The provider page lists how each route signs in, what you need to set up, and which features depend on the account.

Limits

Current limits

The features page lists every capability and limit, and what evidence each compatibility claim is based on.

  • Gmail, Google Calendar, and Google Tasks use your own OAuth client. Guided setup imports a Google Desktop client into the OS keyring before you sign in.
  • Microsoft Graph uses an OAuth client you provide. Corresync does not run a token relay.
  • No desktop notifications on Windows. The queue and approved runner modes still work there.
  • Features depend on the account. Setup shows the route and services that account actually has instead of guessing from the email provider’s name.
