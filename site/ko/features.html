기능

읽기는 여러 계정에서, 쓰기는 계정 하나에만

읽기는 여러 계정을 모아 볼 수 있지만, 쓰기는 항상 계정 하나와 대상 하나를 정해 실행합니다. CLI와 MCP는 같은 정책 검사를 거칩니다.

AI 에이전트로 설정연결 방식 비교

메일

메일 검색, 읽기, 작성, 정리

결과마다 계정, 서비스, 폴더가 표시됩니다. 일부 계정이 실패하면 부분 결과로 표시합니다.

통합 검색과 목록

계정 하나 또는 모든 계정에서 정해진 조건으로 메시지를 찾습니다. 먼저 메타데이터를 보고, 본문과 첨부 파일은 요청한 것만 읽습니다.

초안과 보내기

받는 사람, 제목, 본문, 첨부 파일을 미리 보고 승인합니다. 승인 토큰은 다른 계정이나 바뀐 내용에는 쓸 수 없습니다.

상태 변경과 이동

읽음, 플래그, 라벨, 폴더 이동은 서비스가 제공하는 범위에서만 실행하며, 없는 기능을 흉내 내지 않습니다.

삭제, 결과를 알 수 없는 경우

삭제 같은 작업은 따로 승인해야 합니다. 처리됐는지 알 수 없으면 다시 시도하지 않고 확인이 필요하다고 알려 줍니다.

캘린더

캘린더 일정 보기와 편집

일정마다 캘린더, 시간대, 서비스가 표시됩니다. 생성, 수정, 취소는 선택한 계정과 캘린더의 미리보기를 거칩니다.

통합 일정

여러 계정의 일정을 기간별로 모아 보여 주고, 부분 실패와 기능 제한을 표시합니다.

일정 생성과 수정

제목, 시간, 장소, 참석자, 반복, 알림 등 정해진 필드만 다룹니다. 임의의 속성을 읽고 쓰는 API는 없습니다.

참석자와 취소

초대나 취소 알림처럼 외부로 나가는 작업은 서버가 지원하는 것이 확인되고 따로 승인해야 실행됩니다.

Teams 또는 Google Meet

선택한 캘린더 연결 방식이 지원하면 일정에 참여 링크 하나를 붙일 수 있습니다. Teams 채팅과 채널은 미리보기로 선택할 수 있지만 실환경 확인은 아직 충분하지 않습니다. 통화, 녹화, 프레즌스 감시, 회의 수명 주기 관리는 지원하지 않습니다.

계정과 자동화

계정은 기본으로 분리되고, 자동화는 직접 켜야 합니다

바뀌지 않는 계정 ID

주소나 별칭과 무관한 내부 ID로 세션, 프로필, 동기화 위치, 캐시, 감사 기록을 계정마다 따로 둡니다.

로컬 데이터 가져오기(읽기 전용)

아카이브, Maildir, Thunderbird 프로필, 지원하는 내보내기 중 미리보기를 승인한 것만 정해진 크기 안에서 가져옵니다. 다른 앱의 비밀 정보는 쓰지 않습니다.

모니터링(선택)

모니터링, 에이전트 실행, 외부 전송은 각각 따로 켜며 기본값은 꺼짐입니다. MCP 도구로는 켤 수 없습니다.

메일 내용을 남기지 않는 감사 기록

작업 종류, 결과, 내부 식별자만 기록합니다. 주소, 받는 사람, 제목, 본문, 첨부 파일 이름, 토큰, 승인 값은 남기지 않습니다.

테스트 현황

계약 테스트와 실제 계정 확인

개발 중인 연결 방식은 모두 자격 증명과 개인 정보가 없는 합성 데이터로 계약 테스트를 거칩니다. 실제 환경에서 동작한다고 적는 것은 문서화된 옵트인 실환경 확인을 따로 실행한 경우뿐입니다.

안정 버전

Outlook Web

전용 브라우저 로그인으로 메일과 캘린더를 다룹니다. 합성 계약 테스트 범위와 옵트인 실환경 확인 범위를 문서로 밝힙니다.

실환경 미확인

Graph · Todoist · TickTick · JMAP · IMAP/SMTP · CalDAV

계약과 합성 테스트가 있습니다. 실제 조직 정책과 서버 기능은 로그인 후 계정마다 확인합니다.

설정 후 사용 가능

Gmail · Google 캘린더

본인이 관리하는 Google Cloud 프로젝트의 데스크톱 OAuth 클라이언트로 사용하며, 실환경 확인은 아직 없습니다.

제한 사항

지원하지 않는 기능

  • 임의 작업, 범용 속성 API, 관리자 권한, 테넌트 전체 접근은 제공하지 않습니다.
  • 자동으로 Graph로 넘어가지 않습니다. Google 인증은 로컬에서 로그인 명령을 실행할 때만 시작됩니다.
  • 메일 내용과 캘린더 필드는 명령이나 권한으로 취급하지 않습니다.
  • 실제 메일함 테스트는 옵트인으로만 실행되며 기본 테스트와 CI에서는 실행되지 않습니다.
  • 기능 제한과 부분 실패는 정상 결과처럼 감추지 않습니다.
