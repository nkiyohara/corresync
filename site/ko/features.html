기능

여러 계정을 한눈에, 쓰기는 정확한 한 계정에.

읽기는 계정을 넘나들며 모을 수 있지만, 쓰기는 항상 정확한 계정과 대상에 고정됩니다. CLI와 MCP는 같은 명확히 정의된 사용 사례와 정책 검사를 사용합니다.

설정 시작지원 경로 비교

메일

찾고, 읽고, 작성하고, 안전하게 정리하세요.

각 결과는 원래 계정, 서비스, 폴더 출처를 유지합니다. 일부 계정이 실패하면 전체 성공처럼 보이지 않고 부분 결과로 표시됩니다.

통합 검색과 목록

계정 하나 또는 모든 계정에서 명확히 정의된 검색 조건으로 메시지를 찾습니다. 먼저 메타데이터를 보고, 본문과 첨부 파일은 요청한 항목만 읽습니다.

초안과 보내기

받는 사람, 제목, 본문, 첨부 파일을 정확히 미리 본 뒤 승인합니다. 승인 토큰은 다른 계정이나 변경된 내용에 사용할 수 없습니다.

상태 변경과 이동

읽음, 플래그, 라벨, 폴더 이동을 서비스가 실제로 제공하는 범위에서 실행합니다. 기능이 없으면 조용히 흉내 내지 않습니다.

삭제와 결과 불확실성

파괴적 작업은 별도 승인이 필요합니다. 원격 결과를 알 수 없으면 재시도하지 않고 확인이 필요하다고 반환합니다.

캘린더

계정 경계는 유지하고 일정을 모아 봅니다.

캘린더, 시간대, 서비스 출처가 일정마다 남습니다. 생성, 수정, 취소는 선택한 계정과 캘린더에 묶인 미리보기를 거칩니다.

통합 일정

여러 계정의 일정을 시간 범위로 모으고, 부분 실패와 성능 저하를 명확히 표시합니다.

일정 생성과 수정

제목, 시간, 장소, 참석자, 반복, 알림 등 명확히 정의된 필드만 다룹니다. 임의 속성 API는 제공하지 않습니다.

참석자와 취소

초대나 취소 알림처럼 외부 효과가 있는 작업은 서버가 관찰한 기능과 별도 승인이 모두 필요합니다.

Teams 또는 Google Meet

선택한 캘린더 경로가 지원할 때 일정 속성으로 기본 참여 링크 하나를 요청합니다. 채팅, 통화, 녹화나 회의 수명 주기 관리는 범위 밖입니다.

계정과 자동화

격리는 기본값이고, 자동화는 별도 선택입니다.

안정적인 계정 신원

주소와 별칭이 바뀌어도 독립된 불투명 신원으로 세션, 프로필, 커서, 캐시, 감사 맥락을 분리합니다.

읽기 전용 로컬 가져오기

사용자가 미리보기를 승인한 아카이브, Maildir, Thunderbird 프로필과 지원 내보내기만 제한된 크기로 가져옵니다. 다른 앱의 비밀 정보는 재사용하지 않습니다.

선택적 모니터링

모니터링, 에이전트 실행, 외부 전송은 서로 다른 선택 항목이며 기본으로 꺼져 있습니다. MCP 도구로 켤 수 없습니다.

내용 없는 감사 기록

작업 유형, 결과와 불투명 식별자를 제한적으로 남기되 주소, 받는 사람, 제목, 본문, 첨부 파일명, 토큰과 승인 값은 기록하지 않습니다.

근거 수준

개발 계약과 실사용 관찰을 구분합니다.

각 개발 경로는 자격 증명이나 개인 정보가 없는 합성 고정 데이터로 계약 테스트를 거칩니다. 실사용 호환성 주장은 문서화된 별도 동의 아래 실제 계정에서 관찰한 경우에만 붙습니다.

안정 버전

Outlook Web

v0.7 안정 바이너리에서 구현된 유일한 제공자 어댑터이며, 합성 계약과 명시적 실사용 관찰 범위를 문서화합니다.

개발 경로

Graph · Todoist · TickTick · JMAP · IMAP/SMTP · CalDAV

명확히 정의된 계약과 합성 테스트가 있습니다. 실제 조직 정책과 서버 기능은 로그인 후 계정별로 관찰합니다.

비활성

Gmail · Google 캘린더

코드와 합성 계약은 RC에 포함되지만 운영 환경 OAuth 승인 전에는 모든 진입점이 닫혀 있고 실사용 관찰 전입니다.

명확한 한계

지원하지 않는 기능도 숨기지 않습니다.

  • 임의 제공자 작업, 범용 속성 API, 관리자 권한이나 테넌트 전체 접근은 제공하지 않습니다.
  • Graph는 자동 대체 경로가 아니며, Google 인증은 승인 전 자동으로 시작할 수 없습니다.
  • 메일 내용이나 캘린더 필드는 명령 또는 권한으로 취급하지 않습니다.
  • 실사용 메일함 테스트는 별도 동의가 필요하며 기본 테스트나 CI에서 실행되지 않습니다.
  • 기능 저하와 부분 실패는 정상 결과처럼 감추지 않습니다.
