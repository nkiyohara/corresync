시작하기

설치부터 첫 질문까지, 네 단계면 됩니다.

Corresync는 먼저 로그인하지 않습니다. 주소에서 공개 연결 정보를 찾고, 사용자가 경로를 고른 다음, 별도의 명령으로 그 계정만 로그인합니다.

1단계

Corresync 설치

운영체제에 맞는 방법을 하나 선택하세요. 공식 설치 프로그램은 공개 릴리스의 체크섬과 출처 증명을 확인합니다.

macOS · Linux

curl -LsSf https://corresync.org/install.sh | sh

Windows · PowerShell

powershell -NoProfile -Command "irm https://corresync.org/install.ps1 | iex"

Windows · WinGet

winget install --id nkiyohara.Corresync --exact

Homebrew

brew install nkiyohara/corresync/corresync

Windows · Scoop

scoop bucket add corresync https://github.com/nkiyohara/scoop-corresync
scoop install corresync/corresync

설치 후 버전을 확인하세요.

corr --version

2단계

계정 경로 찾기와 선택

탐색은 자격 증명 없이 유효한 TLS와 공개 정보만 확인합니다. 계정을 추가하거나 로그인을 시작하지 않습니다. 

corr account discover you@example.com

결과를 확인한 뒤 메일과 캘린더 경로를 명시적으로 고르세요. 간단한 설정 명령은 탐색 결과를 보여 주고 선택을 받습니다. 

corr setup you@example.com --alias personal

Google 계정은 지금 어떻게 되나요?

Gmail과 Google 캘린더 코드는 RC에 들어 있지만 운영 환경 OAuth 승인 전까지 경로가 완전히 꺼져 있습니다. 설정 결과에는 “곧 지원”이라고 표시되며 Google 로그인은 시작되지 않습니다. Outlook Web, 명시적으로 선택한 Microsoft Graph, JMAP, IMAP/SMTP, CalDAV는 현재 사용할 수 있습니다.

3단계

선택한 계정에 로그인

로그인은 항상 별도의 명령입니다. 탐색 중이나 자동 선택 과정에서 브라우저 인증을 시작하지 않습니다. 

corr auth login --account personal
  • Outlook Web: 전용으로 보이는 브라우저가 로그인과 사이트 데이터를 소유합니다.
  • Microsoft Graph: 사용 권한이 있는 공개 OAuth 클라이언트를 명시적으로 선택하고, 권한은 운영체제 키체인에 둡니다.
  • JMAP · IMAP/SMTP · CalDAV: 비밀 정보는 키체인 또는 승인한 자격 증명 도우미가 보관하며 설정에는 참조만 남습니다.
  • Google: 승인 전에는 이 명령도 로그인보다 앞에서 중단됩니다.

연결된 계정과 관찰된 기능을 확인합니다.

corr account list

4단계

MCP 클라이언트 연결

아래 명령은 로컬 stdio MCP 서버를 해당 클라이언트에 등록합니다. 원격 MCP URL이나 호스팅 중계는 만들지 않습니다.

Codex

corr mcp setup codex

Claude Code

corr mcp setup claude-code

GitHub Copilot CLI

corr mcp setup github-copilot

Gemini CLI

corr mcp setup gemini-cli

Qwen Code

corr mcp setup qwen-code

Qoder

corr mcp setup qoder

Kimi Code CLI

corr mcp config kimi-code

기타 MCP 클라이언트

corr mcp serve

클라이언트를 한 번 다시 시작한 뒤 메일이나 일정을 물어보세요. 계정을 넘나드는 읽기는 합칠 수 있지만, 모든 쓰기는 먼저 하나의 정확한 계정과 대상을 선택합니다.

완료

첫 작업 실행

CLI와 MCP가 같은 애플리케이션 작업을 사용하므로 어느 쪽에서 시작해도 정책은 같습니다. 

corr mail search --all-accounts --query 'is:unread'
corr agenda list --all-accounts \
  --start 2026-08-12T00:00:00Z \
  --end 2026-08-13T00:00:00Z

보내기, 삭제, 참석자 초대 같은 작업은 검토 결과와 승인 토큰을 먼저 반환합니다. 미리 본 계정·대상·내용이 바뀌면 기존 승인을 사용할 수 없습니다.

막혔을 때

추측하지 말고 상태를 확인하세요.

  • corr doctor로 설치와 로컬 환경을 확인합니다.
  • corr account discover ADDRESS를 다시 실행해 공개 연결 근거를 살펴봅니다.
  • 조직의 MFA, Conditional Access, 관리자 동의, 비활성 프로토콜은 그대로 적용됩니다.
  • 일부 계정만 실패하면 집계 결과에 부분 실패가 표시됩니다.
  • 문제 보고에는 실제 메일, 캘린더, 주소, 토큰이나 자격 증명을 넣지 마세요.
