계정별 연결 방식

브랜드만 보고 기능을 추측하지 않습니다. 로그인 전에 자격 증명 없이 공개 정보를 확인하고, 메일과 캘린더의 연결 방식은 직접 고릅니다.

메일 주소 확인설정 방법 보기

지원 여부 확인

메일 주소의 도메인만으로 지원 여부를 확인합니다

메일 주소를 입력하면 브라우저에서 @ 뒤의 도메인만 떼어 확인 서비스로 보냅니다.

you@example.com처럼 도메인을 포함한 전체 메일 주소를 입력하세요. 완전한 도메인이 확인되기 전에는 요청을 보내지 않습니다.

브라우저 밖으로 나가는 정보는 도메인뿐입니다. @ 앞부분은 전송, 저장, 기록하지 않고 주소 표시줄에도 넣지 않습니다. 확인 서비스는 공개 DNS만 조회하며 기록을 남기거나 로그인을 시작하지 않습니다. 설치 후 로컬에서 corr account discover you@example.com을 실행해도 됩니다.

v0.9 테스트 현황은 연결 방식마다 다릅니다.

아래의 사용 가능하거나 준비 중인 연결 방식은 모두 합성 서비스 계약 테스트와 애플리케이션 테스트를 거쳤습니다. Gmail API 경로는 합성 계약 테스트를 통과했지만 실환경 확인은 아직 없습니다.

Outlook Web과 Microsoft Graph

Outlook Web은 브라우저에서 로그인합니다. Microsoft Graph는 따로 설정한 공개 OAuth 클라이언트로 연결하며 자동 대체 경로가 아닙니다.

Apple iCloud

iCloud Mail과 캘린더를 함께 설정

corr setup은 Apple 문서의 주소 도메인과 서비스 레코드가 모두 확인된 iCloud 사용자 도메인을 알아보고, Apple 공식 IMAP, SMTP, CalDAV 엔드포인트를 제안합니다. 계정 추가 전에 로그인 이름과 연결 방식을 모두 확인할 수 있습니다.

Apple 공식 iCloud Mail 설정과 앱 암호 안내를 확인하세요. 이 프리셋은 합성 계약 테스트를 통과했으며, 옵트인 실환경 확인을 실행해 기록하기 전까지는 실환경 미확인 상태입니다.

Google

Gmail, Google 캘린더, Google Tasks는 직접 만든 OAuth 클라이언트로 연결합니다

본인이 관리하는 Google Cloud 프로젝트에 데스크톱 OAuth 클라이언트를 만들고 안내 설정에서 JSON을 가져오세요. 그 클라이언트로 Google의 일반 브라우저 로그인이 열리며, Corresync 관리형 OAuth는 쓰지 않습니다.

TickTick

프로젝트와 받은 편지함, 검색, 만들기, 수정, 완료, 삭제, 반복, 체크리스트, 라벨, 담당자 한 명, 순서, 제한된 폴링을 지원합니다.

직접 등록한 OAuth 앱(클라이언트 시크릿 방식)을 씁니다. 시크릿은 승인한 자격 증명 저장소에 저장합니다. 다시 열기와 알림 교체는 지원한다고 표시하지 않습니다.

개방형 표준

JMAP, IMAP/SMTP, CalDAV

유효한 TLS가 필요하고, 자격 증명은 운영체제 키체인이나 승인한 자격 증명 도우미에서 가져옵니다. 서버가 제공하는 기능만 씁니다.

J

메일

JMAP

RFC 8620에 따라 읽기, 초안, 서버가 지원하면 전송, 이동, 상태 변경, 승인 후 삭제를 지원합니다.

읽기 전용 계정이거나 Submission 기능이 없으면 그 기능은 사용할 수 없다고 표시합니다.

IM

메일

IMAP / SMTP

폴더, MIME 읽기, 초안, 안전한 이동, 보낸편지함에서 결과를 확인할 수 있는 SMTP 전송을 지원합니다.

UIDPLUS나 보낸편지함 기능이 필요한 작업은 안전하지 않게 흉내 내지 않고 실패합니다.

C

캘린더 · 할 일

CalDAV

VEVENT 캘린더와 VTODO 할 일 목록을 따로 찾고, 제한된 읽기, 반복, 동기화 토큰, 검토 후 조건부 WebDAV/iCalendar 쓰기를 지원합니다.

캘린더 일정 조율 기능과 할 일 기능은 로그인한 뒤 각각 확인합니다.

메일과 캘린더를 따로 연결

메일과 캘린더에 서로 다른 프로토콜을 쓸 수 있습니다

IMAP/SMTP와 CalDAV를 함께 쓰거나 메일 또는 캘린더만 설정할 수 있습니다. 설정, 자격 증명, 동기화 위치, 미리보기, 감사 기록은 계정 ID별로 분리됩니다.

제한 사항

서비스가 지원하지 않는 기능

  • 서비스의 제한은 기능 없음 또는 기능 제한으로 결과에 표시합니다.
  • 자동 탐색은 Google OAuth를 시작하지 않으며, 로컬 로그인 명령만 브라우저를 열 수 있습니다.
  • 자동 탐색은 Graph 권한 요청을 시작하지 않습니다.
  • 회의 링크는 선택한 캘린더 연결 방식이 지원한다고 응답할 때만 요청합니다.
  • 결과를 알 수 없는 쓰기는 확인이 필요하며 자동 재시도하지 않습니다.
