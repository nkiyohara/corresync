경로도 근거도 명확하게

내 계정에 맞는 연결 방식을 고르세요.

Corresync는 브랜드만 보고 기능을 추측하지 않습니다. 로그인 전에 자격 증명 없는 공개 근거를 모으고, 사용자가 메일과 캘린더 경로를 직접 선택합니다.

메일 주소 확인설정 방법 보기

이 주소도 사용할 수 있을까요?

전체 주소를 보내지 않고 지원 여부를 확인하세요.

연결할 메일 주소를 입력하세요. 브라우저 안에서 주소를 나눈 뒤 @ 뒤의 도메인만 확인 서비스로 보냅니다.

you@example.com처럼 도메인을 포함한 전체 메일 주소를 입력하세요. 완전한 도메인이 확인되기 전에는 요청을 보내지 않습니다.

브라우저 밖으로 나가는 정보는 도메인뿐입니다. @ 앞부분은 전송, 저장, 기록하거나 주소 표시줄에 넣지 않습니다. 서비스는 공개 DNS만 읽고 기록을 남기지 않으며 로그인도 시작하지 않습니다. 웹 확인을 건너뛰고 설치 후 corr account discover you@example.com을 로컬에서 실행해도 됩니다.

v0.8의 근거는 경로별로 구분됩니다.

아래의 사용 가능 또는 준비 중인 경로에는 결정적인 합성 공급자 계약과 애플리케이션 테스트가 있습니다. Gmail API 경로는 꺼져 있고 아직 실사용 관찰 전입니다.

Microsoft 경로

신뢰하는 브라우저를 쓰거나 Graph를 명시적으로 선택하세요.

Outlook Web 로그인은 브라우저가 맡습니다. Microsoft Graph는 별도로 설정한 공개 OAuth 클라이언트이며 자동 대체 경로가 되지 않습니다.

Apple iCloud

하나의 안내 흐름에서 iCloud Mail과 캘린더를 설정하세요.

corr setup은 Apple이 문서화한 주소 계열과 서비스 레코드가 모두 검증된 iCloud 사용자 도메인을 인식합니다. Apple 공식 IMAP, SMTP, CalDAV 엔드포인트를 제안하고 계정을 추가하기 전에 모든 로그인 이름과 경로를 검토할 수 있게 합니다.

2F

이중 인증

이중 인증을 켠 뒤 Apple 계정 페이지에서 앱 암호를 만드세요. 안내 흐름은 검토한 로컬 계정을 추가한 후 사용자가 명시적으로 선택한 경우에만 그 페이지를 엽니다.

Apple 공식 iCloud Mail 설정과 앱 암호 안내를 확인하세요. 이 프리셋은 합성 계약 테스트를 통과했으며, 명시적으로 동의한 실제 환경 관찰이 기록되기 전까지는 실제 환경 미관찰 상태입니다.

Google 경로

Gmail, Google 캘린더, Google Tasks는 곧 지원됩니다.

관련 코드는 RC에 포함되어 합성 계약 테스트를 통과했습니다. 하지만 Google 승인 전에는 운영 환경 OAuth가 완전히 꺼져 있어 로그인, 권한 요청, 키체인 접근, API 트래픽이 시작되지 않습니다. Outlook, Microsoft 365, Todoist, TickTick, iCloud, JMAP, IMAP/SMTP, CalDAV는 지금 사용할 수 있습니다.

할 일 경로

평소 쓰는 할 일 서비스를 그대로 연결하세요.

할 일 경로는 메일·캘린더와 별도로 선택합니다. 계정마다 권한, 기능, 동기화 커서, 검토 후 쓰기를 분리합니다.

Microsoft To Do

할 일 목록, 만들기·수정, 완료·다시 열기, 삭제, 반복, 체크리스트, 범주와 제한된 Graph 델타 동기화를 지원합니다.

직접 등록하고 선택할 권한이 있는 Microsoft Graph 공개 클라이언트를 사용합니다.

지금 사용 가능 · 명시적 OAuth

Todoist

프로젝트, 쓰기와 상태 변경, 알림, 반복, 하위 할 일, 라벨, 담당자, 정확한 날짜·시간 의미와 제한된 동기화를 지원합니다.

PKCE 공개 OAuth 클라이언트를 사용하며 요금제에 따른 제한도 그대로 표시합니다.

Ti

지금 사용 가능 · 명시적 OAuth

TickTick

프로젝트와 받은 편지함, 검색, 만들기, 수정, 완료, 삭제, 반복, 체크리스트, 라벨, 한 명의 담당자, 순서와 제한된 폴링을 지원합니다.

직접 등록한 클라이언트 시크릿 방식의 OAuth 앱을 사용합니다. 시크릿은 승인한 자격 증명 저장소에 두며 다시 열기나 알림 교체를 지원한다고 표시하지 않습니다.

개방형 표준

서비스가 실제로 공개한 기능만 조합합니다.

표준 경로는 유효한 TLS와 운영체제 키체인 또는 명시적으로 승인한 자격 증명 도우미를 요구합니다.

J

메일

JMAP

RFC 8620 계약으로 읽기, 초안, 지원 시 제출, 이동, 상태 변경, 승인 후 삭제를 제공합니다.

읽기 전용 계정이나 Submission 기능이 없으면 해당 기능을 사용할 수 없다고 명시합니다.

IM

메일

IMAP / SMTP

폴더, MIME 읽기, 초안, 안전한 이동과 보낸편지함 결과를 확인할 수 있는 SMTP 제출을 제공합니다.

UIDPLUS나 보낸편지함 기능이 필요한 작업은 불안전한 흉내를 내지 않고 실패합니다.

C

캘린더 · 할 일

CalDAV

VEVENT 캘린더와 VTODO 할 일 목록을 따로 탐색하고, 제한된 읽기, 반복, 동기화 토큰, 검토 후 조건부 WebDAV/iCalendar 쓰기를 제공합니다.

캘린더 일정 조율과 할 일 기능은 로그인한 뒤 각각 확인합니다.

계정 하나, 경로 둘

메일과 캘린더가 같은 프로토콜일 필요는 없습니다.

IMAP/SMTP와 CalDAV를 조합하거나 메일 또는 캘린더만 설정할 수 있습니다. 안정적인 계정 신원이 설정, 자격 증명, 커서, 미리보기와 감사 맥락을 분리합니다.

숨은 대체 경로 없음

없는 기능을 있는 것처럼 만들지 않습니다.

  • 제한은 명확히 정의된 기능 또는 성능 저하로 명확히 반환됩니다.
  • 승인 대기 중인 Google 경로는 브라우저, OAuth, 키체인, 세션, 네트워크보다 앞에서 멈춥니다.
  • 자동 탐색은 Graph 권한 요청을 시작하지 않습니다.
  • 선택한 캘린더 경로가 지원한다고 보고할 때만 회의 링크를 요청합니다.
  • 결과를 알 수 없는 쓰기는 확인이 필요하며 자동 재시도하지 않습니다.
