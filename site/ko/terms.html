이용 약관

오픈 소스 권리를 침해하지 않는 명확한 조건.

이 약관은 Corresync 공식 웹사이트, 선택적 도메인 호환성 검사기, 공식 릴리스 인프라와 프로젝트가 운영하는 OAuth 신원에 적용됩니다. 메일과 캘린더 서비스를 연결할 때의 책임도 설명합니다. 소프트웨어 자체는 Apache License 2.0에 따라 제공되며 이 약관은 해당 권리에 조건을 추가하지 않습니다.

시행 및 최종 변경일: 2026년 8월 11일

가장 중요한 원칙

사용 권한이 있는 계정만 연결하세요.

  • 원격 쓰기를 승인하기 전에 미리보기를 확인하세요.
  • 서비스 제공자, 직장, 학교와 관련 법률의 요구 사항을 지키세요.
  • 접근 통제 우회, 서비스 악용 또는 타인에게 해를 주는 용도로 사용하지 마세요.
  • 장치, 키체인, MCP 클라이언트, 모델과 백업을 보호하세요.

01 · 동의와 범위

이 약관이 적용되는 경우

이 약관은 사용자와 Corresync 오픈 소스 프로젝트 관리자 Naoki Kiyohara 사이의 계약입니다. 공식 웹사이트, 선택적 도메인 호환성 검사기, 공식 릴리스 인프라, 프로젝트가 운영하는 OAuth 신원(현재 비활성화된 Corresync Google OAuth 애플리케이션)을 “프로젝트 서비스”라고 합니다. 프로젝트 서비스를 사용하면 이 약관에 동의하는 것이며, 동의하지 않으면 사용하지 마세요.

소프트웨어 사본을 소유, 실행, 연구, 복제, 변경, 배포할 권리는 아래 라이선스가 정합니다. 독립 포크, 제3자 빌드, 서비스 제공자, 패키지 관리자, MCP 클라이언트, 모델과 실행기는 프로젝트 서비스가 아니며 별도 조건이 적용될 수 있습니다.

02 · 오픈 소스 라이선스

소프트웨어는 계속 Apache-2.0입니다

별도 라이선스 고지가 있는 제3자 구성 요소를 제외한 Corresync 소스 코드와 공식 소프트웨어 배포본은 Apache License, Version 2.0에 따라 제공됩니다. 이 약관은 Apache-2.0이 부여하는 권리를 줄이거나 조건을 붙이거나 취소하지 않으며, 소프트웨어 권리를 얻기 위한 조건도 아닙니다. 소프트웨어 사본에 관해 충돌하면 라이선스가 우선합니다.

03 · 이용 자격과 계정 권한

관리하도록 허가받은 계정만 연결하세요

법적 구속력이 있는 동의를 할 수 있고 법률상 사용이 허용된 경우에만 프로젝트 서비스를 이용할 수 있습니다. 서비스 제공자, 계정 소유자, 고용주, 학교, 조직과 관련 법률이 요구하는 모든 권한을 얻는 것은 사용자의 책임입니다. Corresync는 메일함, 캘린더, 테넌트, 위임 사용자 또는 관리자 권한을 주지 않습니다. 인증, MFA, Conditional Access, 관리자 동의와 기존 메일함 권한은 계속 적용됩니다.

04 · 사용자 책임

영향이 생기기 전에 사람이 판단해야 합니다

  • 중요한 작업을 승인하기 전에 미리보기의 계정, 받는 사람, 첨부 파일, 참석자, 날짜, 반복과 다른 필드를 확인하세요.
  • 메일, 첨부 파일, 링크, 캘린더 필드, 가져온 파일과 모니터 이벤트를 명령이나 권한이 아닌 신뢰하지 않는 콘텐츠로 취급하세요.
  • 장치, 운영체제 계정, 브라우저, 키체인, 설정, 로컬 파일, MCP 클라이언트, 모델, 실행기와 백업을 보호하세요.
  • 데이터를 받을 MCP 클라이언트, AI 서비스, 모니터 대상, 자격 증명 도우미와 제공자의 개인정보 조건을 확인하세요.
  • 신뢰할 수 있는 빌드만 설치하고 지원되는 버전을 유지하며, 알 수 없음 또는 부분 완료로 표시된 결과를 제공자 상태와 대조하세요.

05 · 허용되는 사용

우회나 악용에 사용하지 마세요

프로젝트 서비스를 이용해 허가 없이 타인의 계정이나 데이터에 접근하거나 인증, MFA, 관리자 통제, 비활성 서비스, 속도 제한 또는 권한을 우회해서는 안 됩니다. 스팸, 피싱, 악성 코드, 괴롭힘, 불법 감시 또는 기만적 콘텐츠를 보내거나 시스템을 방해·과부하·손상해서도 안 됩니다. 검사기를 네트워크 탐색에 전용하거나 제한을 피해서는 안 되며, Google, Microsoft, 서비스 제공자 또는 에이전트 업체와의 제휴나 보증을 거짓으로 주장해서도 안 됩니다. 선의의 보안 연구는 비공개 채널로 신고하세요.

06 · 서비스 제공자와 제3자

외부 서비스에는 각자의 규칙이 있습니다

선택한 Google, Outlook Web, Microsoft Graph, JMAP, IMAP/SMTP, CalDAV와 로컬 가져오기 경로에는 해당 서비스의 약관, 개인정보 처리방침, 할당량, 관리자 정책과 요금이 적용됩니다. Corresync는 서비스 가용성, 데이터, 인증 흐름, API·웹사이트 변경, 전달 결과 또는 계정 조치를 통제하지 않으며 제3자 링크는 보증을 뜻하지 않습니다.

Gmail, Google 캘린더, Google Tasks는 직접 관리하고 사용할 권한이 있는 Google Cloud 프로젝트의 데스크톱 OAuth 클라이언트를 제공한 경우에만 사용할 수 있습니다. Corresync 관리형 OAuth 신원은 비활성 상태를 유지합니다. Google 계정 접근에는 Google APIs Terms of Service와 관련 제품 정책도 적용됩니다.

선택적 호환성 검사기는 도메인만 단일 목적 Cloudflare Worker와 고정 공개 DNS 해석기에 보냅니다. 결과는 공개 근거일 뿐 호환성, 권한, 로그인이나 서비스 가용성을 보장하지 않습니다.

07 · 개인정보

로컬 우선 데이터 처리

개인정보 처리방침은 각 경로가 접근할 수 있는 데이터, 필요한 권한, 로컬 저장, 도메인 검사기, 클라이언트와 모델이 받을 수 있는 데이터, 연결 해제와 권한 삭제를 설명하며 이 약관의 일부입니다. 자동 공개 오류 피드백은 기본으로 꺼져 있으며 원시 오류, 계정 데이터, 자격 증명, 메일이나 캘린더 콘텐츠 전송을 허용하지 않습니다.

08 · 변경, 중단과 종료

프로젝트 서비스는 바뀔 수 있습니다

프로젝트는 보안, 법률 준수, 제공자 요구 사항 또는 악용 방지를 위해 프로젝트 서비스, 연결 방식, OAuth 자격 증명, 릴리스 채널이나 버전 지원을 변경·중단·종료할 수 있습니다. 사용자는 언제든 이용을 중단하고 개인정보 처리방침에 따라 로컬 계정을 삭제하고 제공자 권한을 취소하며 애플리케이션을 제거할 수 있습니다. 라이선스 소유권, 면책, 책임 제한과 성질상 존속해야 하는 조항은 종료 후에도 유효합니다.

09 · 보증 부인과 책임 제한

중단이나 오류가 없다고 보장하지 않습니다

법률이 허용하는 최대 범위에서 프로젝트 서비스는 명시적·묵시적 보증 없이 “있는 그대로” 및 “제공 가능한 범위에서” 제공됩니다. 안전, 가용성, 정확성, 무오류 또는 모든 제공자, 계정 정책, 클라이언트, 모델과 플랫폼과의 호환성을 보장하지 않습니다.

법률이 허용하는 최대 범위에서 프로젝트, 관리자와 기여자는 프로젝트 서비스로 인한 간접, 부수적, 특별, 결과적 또는 징벌적 손해와 데이터, 메시지, 캘린더 일정, 이익, 영업권이나 접근 권한 손실에 책임지지 않습니다. 특정 배제나 제한을 허용하지 않는 지역에서는 합법적인 범위에서만 적용합니다. 소프트웨어 사본의 보증과 책임에는 Apache-2.0 제7조와 제8조가 별도로 적용됩니다.

10 · 약관 변경

최신 약관은 계속 공개됩니다

프로젝트 서비스, 법률과 정책 변화를 반영하기 위해 약관을 바꿀 수 있습니다. 시행일은 페이지 위에 표시하고 중요한 변경은 이 페이지와 릴리스 노트에 공개하며 이전 버전은 소스 기록에 남깁니다. 법률이 별도 통지나 동의를 요구하지 않는 한, 변경 후에도 프로젝트 서비스를 사용하면 변경된 약관에 동의한 것으로 봅니다.

11 · 연락처

약관 질문과 보안 신고

민감한 데이터가 없는 질문은 Corresync GitHub 이슈로 보내 주세요. 보안 취약점이나 비공개 세부 정보가 필요한 문제는 GitHub 비공개 보안 신고를 사용하세요. 공개 이슈에 실제 자격 증명, 메시지, 캘린더 데이터나 개인정보를 포함하지 마세요.
