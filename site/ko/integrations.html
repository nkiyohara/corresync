공개됨

소스 제공

소스 제공

버전이 붙은 네이티브 패키지를 이 저장소에서 생성하고 테스트합니다. 공급자의 공식 디렉터리에 등록됐다고 주장하지는 않습니다.

미등록

미등록

corr setup으로 검토된 MCP 직접 설정을 사용할 수 있습니다. 마켓 제출은 네이티브 메타데이터와 상위 검토가 준비된 뒤에 합니다.

로컬 실행

마켓에 등록돼도 호스팅 에이전트나 비공개 터널이 켜지지는 않습니다.

Corresync는 로컬 stdio 서버와 로컬 계정 상태만 제공합니다. 플러그인 형식이 있더라도 호스팅 ChatGPT, 클라우드 에이전트, Kiro Web, 원격 샌드박스에서는 접근할 수 없습니다.

호스팅 릴레이나 비공개 MCP 터널을 쓰면 데이터 경로가 새로 생깁니다. 그러려면 별도의 아키텍처 결정, 동의, 개인정보 고지, 철회 방법, 보안 검토가 필요합니다.
