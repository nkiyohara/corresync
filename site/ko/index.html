여러 계정의 메일, 일정, 할 일을 로컬에서 한 번에 다룹니다

업무용과 개인용 메일, 캘린더, 할 일을 Codex, Claude Code, 다른 MCP 에이전트, 터미널에서 씁니다. 로그인과 권한은 계정마다 따로 두고, 검색, 일정 확인, 답장은 정해진 명령과 도구로 처리합니다.

지원 서비스: Outlook · Gmail · Google 캘린더 · Microsoft To Do · Todoist · TickTick · 개방형 표준. 어떤 방식으로 연결되고 무엇을 할 수 있는지는 계정마다 표시됩니다. 서비스 상세 보기

AI 에이전트로 설정내 메일 지원 여부 확인

로그인은 브라우저나 운영체제 키체인에서 처리하며, Corresync가 관리하는 비밀 정보는 에이전트에 넘기지 않습니다. 메일 전송처럼 영향이 큰 작업은 미리보기를 확인하고 승인해야 실행됩니다.

Corresync 설정

데스크톱 에이전트가 Corresync를 설치하거나 업데이트하고 번들 Agent Skill을 설치합니다. 변경 사항은 직접 검토하고 승인하세요.

독립 실행형 CLI를 권장합니다. 새로 설정하면 검증된 자동 업데이트가 켜집니다. 이미 설치되어 있으면 직접 바꾸지 않는 한 패키지 관리자, 구성, 업데이트 설정을 그대로 둡니다.

Codex로 설정 Claude Code로 설정

사용하는 데스크톱 앱을 선택하면 설정 요청이 미리 입력된 상태로 열립니다. 내용을 확인한 뒤 직접 보내세요.

이 컴퓨터에서 명령을 실행할 수 있는 ChatGPT Codex 또는 Claude Code 데스크톱 앱이 필요합니다. 권한 확인 창이 뜨면 승인하세요. 관리자 권한은 필요 없습니다. 로그인과 다단계 인증은 직접 하고, 비밀번호나 인증 코드는 채팅에 붙여넣지 마세요.

휴대폰으로 보고 있다면 설정할 컴퓨터에서 이 페이지를 열거나, 안내를 복사해 그 컴퓨터로 옮기세요.

데스크톱 앱이 열리지 않으면 아래 설정 요청을 복사해 에이전트에 붙여넣으세요.

하던 설정이 있으면 이어서 진행합니다. 연결 방식은 자격 증명 없이 찾고, 계정과 에이전트 설정은 적용 전에 보여 줍니다. 로그인은 따로 실행합니다. 다른 설치 방법과 MCP 클라이언트별 명령은 시작 안내에서 확인할 수 있습니다.

여러 계정을 MCP 서버 하나로업무용과 개인용 계정은 섞이지 않고, 결과마다 어느 계정과 서비스에서 왔는지 표시됩니다.
에이전트는 자격 증명을 받지 않음로그인은 화면에 보이는 브라우저나 운영체제 키체인에서 처리합니다. 원격 중계 서버는 없습니다.
확인 후 실행전송이나 삭제 같은 작업은 먼저 서버가 검토 내용을 보여 주며, 승인은 한 번만 쓸 수 있습니다.

Google 계정

Google은 직접 만든 OAuth 클라이언트로 연결합니다

본인이 관리하는 Google Cloud 프로젝트에 데스크톱 OAuth 클라이언트를 만들고, 내려받은 JSON을 안내 설정에서 가져온 뒤 평소 쓰는 브라우저에서 로그인합니다. 클라이언트 자격 증명과 계정 권한은 키체인에 저장되고, Corresync 관리형 Google OAuth는 꺼져 있습니다. 화면별 설정 안내 보기.

안전장치

처음 실행하면 검토 내용만 보여 줍니다

영향이 큰 명령은 먼저 검토 내용을 돌려줍니다. 승인은 요청자, 계정, 서비스, 대상, 내용에 묶이고, 만료되며 한 번만 쓸 수 있습니다.

  • 에이전트는 정해진 도구만 씁니다. 비밀번호, Cookie, OAuth 권한은 MCP나 설정에 들어가지 않습니다.
  • 로컬에서만 실행됩니다. MCP 서버는 이 컴퓨터에서 stdio로 통신합니다.
  • 결과를 모르면 멈춥니다. 성공했는지 알 수 없는 원격 쓰기는 자동으로 다시 시도하지 않습니다.
  • 메일 내용은 데이터로만 취급합니다. 메일에 적힌 내용으로 명령을 실행하거나 에이전트를 시작할 수 없습니다.

연결 방식

서비스 자체 API와 개방형 표준을 지원합니다

메일과 캘린더의 연결 방식은 따로 고릅니다. 한 계정에서 IMAP/SMTP 메일과 CalDAV 캘린더를 함께 쓸 수도 있습니다.

브라우저 소유

Outlook Web

Outlook 로그인은 화면에 보이는 전용 브라우저에서 직접 합니다. 메일과 캘린더 작업을 지원합니다.

명시적 OAuth

Microsoft Graph · Google은 직접 소유한 클라이언트로

Microsoft Graph는 사용 권한이 있는 공개 클라이언트를 씁니다. Google은 본인이 만든 데스크톱 OAuth 클라이언트를 씁니다.

개방형 표준

JMAP · IMAP/SMTP · CalDAV

암호화된 엔드포인트에 연결합니다. 자격 증명은 운영체제 키체인이나 사용자가 승인한 자격 증명 도우미에서 가져옵니다.

계정을 추가하기 전에 확인하세요. 서비스 안내에서 로그인 방식, 필요한 설정, 계정에 따라 달라지는 기능을 볼 수 있습니다.

제한 사항

현재 지원하지 않거나 직접 준비해야 하는 것

  • Gmail, Google 캘린더, Google Tasks에는 본인이 만든 OAuth 클라이언트가 필요합니다. 안내 설정에서 데스크톱 클라이언트 자격 증명을 키체인으로 가져온 다음 로그인합니다.
  • Microsoft Graph OAuth 클라이언트는 사용자가 준비합니다. Corresync는 토큰 중계 서비스를 운영하지 않습니다.
  • Windows 데스크톱 알림은 아직 지원하지 않습니다.
  • 기능은 계정별로 확인합니다. 메일 주소의 브랜드만 보고 추측하지 않습니다. 설정할 때 그 계정의 연결 방식과 서비스를 보여 줍니다.
