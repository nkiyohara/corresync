계정마다 흩어진 일을, 하나의 로컬 MCP로.

업무용과 개인용 메일, 캘린더, 할 일을 Codex, Claude Code, MCP 에이전트와 터미널에 연결하세요. Corresync는 계정별 신원과 권한을 분리한 채 하나의 타입화된 인터페이스로 찾기, 계획하기, 후속 처리와 실행을 이어 줍니다.

매일 쓰는 서비스를 중심으로: Outlook · Gmail · Google 캘린더 · Microsoft To Do · Todoist · TickTick · 개방형 표준. 연결 경로와 기능은 계정별로 명확히 표시합니다. 서비스 상세 보기

로그인은 브라우저나 운영체제 키체인이 맡습니다. Corresync가 관리하는 비밀 정보를 에이전트에 넘기지 않으며, 중계 서버도 없습니다. 중요한 쓰기 작업은 정확한 미리보기를 확인하고 승인한 뒤에만 실행됩니다.

MCP 하나로 모든 계정 연결업무용과 개인용 신원은 분리하고, 결과에는 원래 계정과 서비스가 표시됩니다.
에이전트에 비밀 정보 없음로그인은 보이는 브라우저나 운영체제 키체인이 맡으며, 원격 중계 서버가 없습니다.
미리보기 후 실행전송과 파괴적 작업은 서버가 만든 검토 화면과 짧은 일회성 승인을 거칩니다.

Google 지원 현황

직접 소유한 OAuth 클라이언트로 Google을 연결하세요.

직접 관리하는 Google Cloud 프로젝트에 데스크톱 OAuth 클라이언트를 만들고, 안내 설정에서 다운로드한 JSON을 가져온 뒤 평소 쓰는 브라우저에서 로그인합니다. 클라이언트 자격 증명과 계정 권한은 키체인에 남고, Corresync 관리형 Google OAuth는 비활성 상태를 유지합니다. 화면별 안내를 따라하세요.

설치 후 세 단계

선택하고, 로그인하고, 물어보세요.

Corresync는 서비스 경로를 미리 고르지 않습니다. 먼저 자격 증명 없이 공개 정보를 확인하고, 사용자가 명시적으로 선택한 계정 경로만 추가한 뒤 해당 계정의 로그인을 시작합니다.

1 · 선택 및 로그인

corr setup you@example.com --alias personal
corr auth login --account personal

탐색 단계에서는 페이지를 열지 않습니다. 별도의 로그인 명령은 선택한 경로만 사용합니다.

2 · 에이전트 연결

corr mcp setup codex

로컬 stdio 서버를 등록한 뒤 클라이언트를 한 번 다시 시작하세요.

보이는 안전장치

첫 호출에서 바로 전송하지 않습니다.

중요한 작업은 먼저 검토 화면을 반환합니다. 승인은 호출자, 계정, 서비스, 대상, 내용, 만료 시각에 묶이며 한 번만 쓸 수 있습니다.

  • 에이전트에는 명확히 정의된 도구만 제공합니다. 비밀번호, Cookie, OAuth 권한은 MCP나 설정에 들어가지 않습니다.
  • 로컬에서만 실행됩니다. MCP는 로컬 stdio로 통신하며 호스팅 중계가 없습니다.
  • 결과가 불확실하면 멈춥니다. 상태를 알 수 없는 원격 쓰기를 자동 재시도하지 않습니다.
  • 메일 내용은 신뢰하지 않는 데이터입니다. 명령 실행이나 에이전트 시작 권한을 줄 수 없습니다.

기존 연결 방식 그대로

필요하면 기본 API를, 가능하면 개방형 표준을.

메일과 캘린더 경로를 따로 선택할 수 있어 IMAP/SMTP 메일과 CalDAV 캘린더를 한 계정에서 조합할 수도 있습니다.

브라우저 소유

Outlook Web

대화형 로그인은 전용으로 보이는 브라우저에 남고, 메일과 캘린더에는 명확히 정의된 작업을 제공합니다.

명시적 OAuth

Microsoft Graph · Google은 직접 소유한 클라이언트로

Graph는 사용 권한이 있는 공개 클라이언트를 씁니다. Google은 직접 소유한 데스크톱 OAuth 클라이언트를 사용합니다.

개방형 표준

JMAP · IMAP/SMTP · CalDAV

암호화된 엔드포인트와 운영체제 키체인 또는 명시적으로 승인한 자격 증명 도우미를 사용합니다.

선택하기 전에 세부 정보를 확인하세요. 서비스 안내에서 정확한 로그인 방식, 설정 요건, 계정별 기능을 함께 볼 수 있습니다.

한계도 투명하게

할 수 없는 일까지 제품의 일부입니다.

  • Gmail, Google 캘린더, Google Tasks는 직접 소유한 OAuth 클라이언트로 사용할 수 있습니다. 안내 설정이 명시적 로그인 전에 데스크톱 클라이언트 자격 증명을 키체인으로 가져옵니다.
  • Microsoft Graph OAuth 클라이언트는 사용자가 준비합니다. Corresync는 토큰 중계 서비스를 운영하지 않습니다.
  • Windows 데스크톱 알림은 아직 지원하지 않습니다.
  • 기능은 계정별로 확인합니다. 이메일 브랜드만으로 추측하지 않고 설정 과정에서 해당 계정의 연결 경로와 서비스를 보여 줍니다.
