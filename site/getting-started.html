Getting started

Getting started in four steps

Install corr, add your work or personal email and calendar accounts, register the local MCP server with your agent, and ask a question that covers them. Each account keeps its own sign-in, even when a search or agenda combines results. Outlook Web sign-in happens in a browser; API and standards credentials are kept in your OS keyring. Agents never receive the credentials Corresync manages. The MCP connection is local stdio, with no hosted relay.

Start at step 1 Check your provider first
  1. 1

    Install corr

    Pick your platform. Installing only gives you the corr command. No account is added and nothing signs in until you do it.

    macOS · Linux

    curl -LsSf https://corresync.org/install.sh | sh

    Installs the verified stable release for your user account. You can read install.sh first. It does not change any account or MCP client.

    Windows · PowerShell

    powershell -NoProfile -Command "irm https://corresync.org/install.ps1 | iex"

    Installs without administrator rights and changes only your user PATH. You can read install.ps1 first. Your organization’s policy still applies.

    Other installation methods

    If you install with a package manager, that package manager handles upgrades and removal.

    Windows · WinGet

    winget install --id nkiyohara.Corresync --exact

    Microsoft-reviewed manifest, managed by WinGet.

    macOS · Linux · Homebrew

    brew install nkiyohara/corresync/corresync

    Homebrew builds the latest stable tagged source.

    Windows · Scoop

    scoop bucket add corresync https://github.com/nkiyohara/scoop-corresync
scoop install corresync/corresync

    Uses the checksum-pinned Corresync Scoop bucket.

    Linux releases also include .deb, .rpm, and .apk packages. Direct archives, checksums, Sigstore provenance, and the Claude Desktop .mcpb are available from the latest release.

    Verify

    corr --version

    Automatic updates · turn on for an existing configuration 

    corr config set updates.auto_install true

    Since 0.9.2, new standalone configurations turn on signed, verified automatic updates. Existing settings are kept; use this command to turn on installation for an existing configuration. Homebrew, Scoop, and WinGet installs are updated by their package manager. An interactive update restarts the session owner and then runs the updated command. MCP, configuration changes, and machine-readable output never install an update. Turn installation off with corr config set updates.auto_install false.

    Optional · preview releases

    corr config set updates.channel preview
corr update

    Stable is the default. Preview releases are signed and verified the same way as stable ones. To go back, run corr config set updates.channel stable. Corresync never downgrades, and previews are not published to package managers.

    macOS release binaries are signed with a Developer ID and notarized by Apple. Windows binaries are not yet Authenticode-signed, so verify the download rather than overriding Gatekeeper or SmartScreen. Archives, packages, checksums, and signed provenance are on the release page.

  2. 2

    Set up your mail and calendar account

    Run one command. Guided setup asks for your email address, looks up the likely mail and calendar services without using credentials, explains the options, and shows a final review before it adds anything.

    Signing in, or using an external credential, is a separate step that you choose after that review. The wizard can then run a short connection check or add another account. corr settings opens the same keyboard-friendly flow; set CORRESYNC_ACCESSIBLE=true for plain line-by-line prompts that work with screen readers, and type :cancel to leave an input step.

    Outlook Web uses Microsoft’s own browser sign-in. Microsoft Graph, JMAP, IMAP/SMTP, and CalDAV also work when your provider supports them and you choose that route and where its credential comes from. The lookup itself never opens a browser, reads a keyring, or asks an administrator for consent.

    Using iCloud? corr setup recognises iCloud Mail and Calendar together for @icloud.com, @me.com, and @mac.com addresses, or from complete verified service records for a custom iCloud domain. After you approve the account, it explains that Apple requires two-factor authentication and an app-specific password. Your operating system asks for that password itself; Corresync never receives it.

    Using Google? Create a Desktop OAuth client in a Google Cloud project you control. Guided setup checks the downloaded JSON and imports the generated credential into your OS keyring. You then sign in through the browser as a separate step.

    Check your address without sending it · how sign-in works

    Guided setup · recommended

    corr setup

    The wizard checks what is already set up, can add shell completion, and continues from the first unfinished step. It shows each account route before adding it and keeps sign-in as a separate step. Then you pick the agents it found, review one plan for all of them, and it applies and checks each one.

    Advanced or scripted setup

    corr setup you@example.com --alias personal
corr auth login --account personal
corr doctor --account personal

    These commands don’t prompt, so you can use them in scripts.

    iCloud Mail + Calendar · available now

    The guided preset adds both services, can use one credential handle you reviewed for both, and shows when each last signed in without reading any content. Read Apple’s app-specific password guide before connecting.

    Gmail · Google Calendar · Google Tasks

    The Google OAuth guide shows how to create a Desktop client and pick only the services you need. The client credential and the account grant are both stored in the OS keyring.

  3. 3

    Connect your agent

    One command adds Corresync as a local stdio MCP server to the agent’s own configuration, using absolute paths and no remote endpoint. Restart the agent afterwards.

    Codex

    corr mcp setup codex

    Verify with codex mcp get corresync.

    Claude Code

    corr mcp setup claude-code

    User or project scope; verify with claude mcp get corresync.

    GitHub Copilot CLI

    corr mcp setup github-copilot

    Verify with copilot mcp get corresync.

    Gemini CLI

    corr mcp setup gemini-cli

    Verify with gemini mcp list.

    Qwen Code

    corr mcp setup qwen-code

    Verify with qwen mcp list.

    Qoder

    corr mcp setup qoder

    Verify with qodercli mcp list.

    Kimi Code CLI

    corr mcp config kimi-code

    Prints the registration to add to Kimi’s MCP configuration.

    Any MCP client

    corr mcp serve

    Plain stdio server. Point any MCP client at this command.

    Every client gets the same 43 tools and two read-only monitor resources. See what agents can and cannot do. Codex and Claude Code users can also install the bundled plugin and Agent Skill.

  4. 4

    Ask your first question

    Reads can cover several accounts at once without merging them. Writes always target one account. Some prompts to try:

    • “Search every account for the message from Ana about the quarterly plan.”
    • “What’s on all my calendars tomorrow morning?”
    • “Draft a reply to Ana. I’ll review the preview before anything is sent.”

    Each result shows its account and provider. If one route fails, the result is marked as a partial failure and still shows what succeeded.

    When you or the agent ask to send, Corresync returns a review of the exact message. It is sent only when you approve that exact message (same account, recipients, and content): --approve in the CLI, or the separate mail_send_commit tool over MCP. The approval is short-lived and works once.
