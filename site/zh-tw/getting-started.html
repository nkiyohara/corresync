開始使用

使用 AI 代理設定 Corresync

使用本機桌面代理安裝或更新 Corresync、新增帳號並安裝 Corresync Agent Skill。請在應用程式中確認並送出請求，在瀏覽器中自行完成登入和多因素驗證。

Read https://corresync.org/setup-instructions.txt and follow it to install or update Corresync on this computer and connect it to this desktop agent, including installing and verifying the Corresync Agent Skill.   1. 1

    安裝 corr

    這一步只安裝程式，不會新增帳號，也不會登入。

    macOS · Linux

    curl -LsSf https://corresync.org/install.sh | sh

    為目前使用者安裝經過驗證的 stable 版本。執行前可以先看指令碼。

    Windows · PowerShell

    powershell -NoProfile -Command "irm https://corresync.org/install.ps1 | iex"

    不需要系統管理員權限，只會更新目前使用者的 PATH。可以先看指令碼。

    其他安裝方式

    由套件管理工具負責更新和解除安裝。

    Windows · WinGet

    winget install --id nkiyohara.Corresync --exact

    macOS · Linux · Homebrew

    brew install nkiyohara/corresync/corresync

    Windows · Scoop

    scoop bucket add corresync https://github.com/nkiyohara/scoop-corresync
scoop install corresync/corresync

    Linux 的 .deb、.rpm、.apk、直接下載的封存檔、checksum、Sigstore 來源證明和 Claude Desktop .mcpb 都放在最新版本頁面。

    驗證

    corr --version

    自動更新 · 在既有設定中啟用

    corr config set updates.auto_install true

    從 0.9.2 起，新設定預設啟用經簽章和驗證的自動更新，既有設定不變。上面的指令可為既有設定啟用。MCP 或機器可讀輸出不會觸發安裝。關閉請執行 corr config set updates.auto_install false。

  2. 2

    設定郵件和行事曆帳號

    先執行一個指令。引導程式會詢問電子郵件地址，不用憑證就找出郵件和行事曆服務，說明可選的連線方式，並在新增帳號前顯示確認畫面。

    確認後，登入或讀取外部憑證是另外的選項。接著可以檢查連線或新增其他帳號。corr settings 使用同一套鍵盤操作流程。螢幕閱讀器使用者可設定 CORRESYNC_ACCESSIBLE=true，改成逐行提示。輸入 :cancel 可以離開目前的輸入步驟。

    Outlook Web 使用服務供應商的瀏覽器登入。服務支援、且你選了對應的連線方式或憑證存放位置時，也可以用 Microsoft Graph、JMAP、IMAP/SMTP 和 CalDAV。查詢連線方式時不會開啟瀏覽器、讀取鑰匙圈或要求管理員同意。

    使用 iCloud？corr setup 會辨識 @icloud.com、@me.com、@mac.com 位址，以及服務記錄完整且通過驗證的 iCloud 自訂網域，並同時設定郵件和行事曆。核准帳號後，引導程式會說明 Apple 雙重認證和 App 專用密碼的要求。密碼由作業系統直接詢問，Corresync 不會收到。

    使用 Google？在你自己管理的 Google Cloud 專案中建立桌面版 OAuth 用戶端。引導式設定會檢查下載的 JSON，先把憑證匯入作業系統鑰匙圈，再由你在瀏覽器登入。

    不傳送完整位址也能檢查 · 登入由誰處理

    引導式設定 · 建議

    corr setup

    引導程式會先檢查目前的本機狀態，可選擇安裝 Shell 補全，並從第一個未完成的步驟繼續。帳號的連線方式會在儲存前預覽，登入另外進行。接著可勾選多個偵測到的 AI 代理，確認本機整合計畫後逐一套用並驗證。

    進階用法或指令碼設定

    corr setup you@example.com --alias personal
corr auth login --account personal
corr doctor --account personal

    這些指令不會互動詢問，適合指令碼和自動化。

    iCloud 郵件與行事曆 · 已支援

    引導式設定預設會新增兩項服務，可共用一個確認過的憑證參照，並在不讀取內容的情況下顯示最近一次驗證狀態。連線前請先看 Apple 官方的App 專用密碼說明。

    Gmail · Google 行事曆 · Google Tasks

    請參考Google OAuth 圖解說明。只啟用需要的 API，用戶端憑證和帳號授權都存放在本機鑰匙圈。

  3. 3

    連接你使用的 AI 代理

    指令會把本機 stdio MCP 的絕對路徑寫入用戶端設定，不建立遠端端點。完成後重新啟動用戶端。

    Codex

    corr integrations setup codex

    執行 corr integrations doctor codex 驗證 MCP 連線和隨附的 Agent Skill。

    Claude Code

    corr integrations setup claude-code

    執行 corr integrations doctor claude-code 驗證 MCP 連線和隨附的 Agent Skill。

    GitHub Copilot CLI

    corr mcp setup github-copilot

    Gemini CLI

    corr mcp setup gemini-cli

    Qwen Code

    corr mcp setup qwen-code

    Qoder

    corr mcp setup qoder

    Kimi Code CLI

    corr mcp config kimi-code

    其他 MCP 用戶端

    corr mcp serve
  4. 4

    查詢所有帳號

    讀取可以跨帳號，但帳號不會合併；寫入要先確認預覽再送出。

    • 「在所有帳號裡找 Ana 寄來、關於季度計畫的郵件。」
    • 「明天上午我所有的行事曆裡有哪些行程？」
    • 「草擬給 Ana 的回覆，傳送前先讓我看預覽。」

    結果會標示帳號和服務；某個連線方式失敗時標示為部分失敗。傳送時，只有帳號、收件人和內容與預覽完全一致，才能用 CLI 的 --approve 或 MCP 的送出工具送出。核准有時效且只能用一次。
