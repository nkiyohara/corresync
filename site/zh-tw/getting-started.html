開始使用

從安裝到第一次回答，清晰的四個步驟。

安裝 corr，新增工作或個人帳號，把本機 MCP 註冊到智慧體，然後提出跨帳號問題。即使結果合併展示，每個帳號的身分和授權仍然隔離。Outlook Web 登入由瀏覽器管理；API 和標準協議的 授權 留在系統鑰匙圈；MCP 只透過本機 stdio 通訊。

從第 1 步開始先檢查支援情況
  1. 1

    安裝 corr

    這裡只安裝程式，不新增帳號，也不會登入。

    macOS · Linux

    curl -LsSf https://corresync.org/install.sh | sh

    為目前使用者安裝已驗證的 stable 版本。執行前可閱讀指令碼。

    Windows · PowerShell

    powershell -NoProfile -Command "irm https://corresync.org/install.ps1 | iex"

    無需管理員權限，只更新目前使用者的 PATH。可先閱讀指令碼。

    其他安裝方式

    交給包管理器管理升級與解除安裝。

    Windows · WinGet

    winget install --id nkiyohara.Corresync --exact

    macOS · Linux · Homebrew

    brew install nkiyohara/corresync/corresync

    Windows · Scoop

    scoop bucket add corresync https://github.com/nkiyohara/scoop-corresync
scoop install corresync/corresync

    Linux 的 .deb、.rpm、.apk，直接下載包、checksum、Sigstore 來源證明 和 Claude Desktop .mcpb 都在最新版本中。

    驗證

    corr --version

    可選 · 自動更新 獨立安裝版 版本

    corr config set updates.auto_install true

    只自動安裝已簽名並驗證的獨立安裝版；MCP 呼叫或機器可讀輸出期間不會更新。

  2. 2

    設定郵件與行事曆帳號

    第一次只需執行一個指令。引導程式會詢問電子郵件地址，在不讀取認證資料的情況下尋找郵件與行事曆服務、說明可選路徑，並在新增帳號前顯示完整預覽。

    登入或讀取外部認證資料始終是確認後的獨立選擇。接著還可檢查連線或繼續新增其他帳號。corr settings使用同一套鍵盤友善流程；螢幕閱讀器使用者可設定CORRESYNC_ACCESSIBLE=true，改用逐行提示；輸入:cancel即可安全離開目前的輸入步驟。

    Outlook Web 使用由服務供應商掌控的瀏覽器登入。Microsoft Graph、JMAP、IMAP/SMTP 與 CalDAV 也可在服務供應商支援，且你明確選擇相應路徑或認證資料存放位置時使用。探索過程不會開啟瀏覽器、讀取鑰匙圈，也不會啟動管理員同意流程。

    使用 iCloud？corr setup會辨識@icloud.com、@me.com、@mac.com，以及具備完整且已驗證服務記錄的 iCloud 自訂網域，並一次設定郵件與行事曆。新增帳號後，引導程式會說明 Apple 雙重認證和 App 專用密碼要求。密碼由作業系統的認證資料介面直接接收，不會經過 Corresync。

    使用 Google？Gmail、Calendar 和 Tasks API 程式碼已在 RC 中，但正式環境 OAuth 等待審核，因此路徑完全關閉，Google 登入無法啟動。暫時請使用 Google 官方 Workspace MCP。

    不傳送完整位址即可檢查 · 瞭解登入歸屬

    引導設定 · 建議

    corr setup

    引導程式會先檢查目前的本機狀態，視需要安裝 Shell 補全，並從尚未完成的步驟繼續。帳號路徑會在儲存前預覽，登入仍是獨立操作；接著可複選偵測到的代理程式，統一確認本機整合計畫，再逐一套用與驗證。

    進階用法或指令碼設定

    corr setup you@example.com --alias personal
corr auth login --account personal
corr doctor --account personal

    原有指令維持非互動行為，適合指令碼與自動化。

    iCloud 郵件與行事曆 · 現已支援

    引導預設會新增兩項服務，可共用一個經過確認的認證資料參照，並在不讀取郵件內文或行程內容的情況下顯示最近一次認證狀態。連線前請閱讀 Apple 官方的App 專用密碼說明。

    Google · 審核前的臨時方式

    參閱 Google 官方Workspace MCP 設定指南。該服務目前是 Developer Preview。

  3. 3

    連線你常用的智慧體

    命令會把本機 stdio MCP 的絕對路徑寫入用戶端自己的設定，不建立遠端端點。之後重啟用戶端。

    Codex

    corr mcp setup codex

    Claude Code

    corr mcp setup claude-code

    GitHub Copilot CLI

    corr mcp setup github-copilot

    Gemini CLI

    corr mcp setup gemini-cli

    Qwen Code

    corr mcp setup qwen-code

    Qoder

    corr mcp setup qoder

    Kimi Code CLI

    corr mcp config kimi-code

    任意 MCP 用戶端

    corr mcp serve
  4. 4

    跨所有帳號提問

    讀取可以跨帳號但不會合併身分；寫入則先審閱，再單獨提交。

    • “在所有帳號裡找 Ana 發來的季度計劃郵件。”
    • “明天上午所有行事曆裡有什麼安排？”
    • “起草給 Ana 的回覆，傳送前讓我確認。”

    結果保留帳號和供應商；失敗路徑顯示為部分失敗。傳送時，只有與審閱過的帳號、收件人和位元組完全一致的內容才能透過 CLI --approve 或 MCP 提交 工具提交。核准短時且單次有效。
