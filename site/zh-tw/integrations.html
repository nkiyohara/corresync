狀態說明

相容、封裝和發布是不同的狀態

已發布

已發布

已核對所示版本的外部公開紀錄。穩定版發布流程會在發布後再核對一次。

原始碼可用

原始碼可用

儲存庫會產生並測試含版本號的原生封裝，但不宣稱已列入廠商的官方目錄。

尚未上架

尚未上架

可以用 corr setup 完成經過審查的直接 MCP 設定。原生中繼資料和上游審查就緒後才會送出上架申請。

只在本機執行

上架目錄不會啟用雲端代理或私人通道

Corresync 只提供本機 stdio 服務和本機帳號狀態。即使有對應的外掛格式，託管版 ChatGPT、雲端代理、Kiro Web 和遠端沙箱也無法存取它。

託管中繼或私人 MCP 通道會產生新的資料路徑，需要另外的架構決策、同意、隱私揭露、撤銷機制和安全審查。
