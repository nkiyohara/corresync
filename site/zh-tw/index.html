郵件 · 行事曆 · 待辦

用一個本機 MCP 處理各帳號的郵件、行事曆和待辦

把工作和個人的郵件、行事曆和待辦連到 Codex、Claude Code、其他 MCP 代理程式或終端機。你可以搜尋、排行程、追蹤和處理事情，各帳號的登入和授權彼此分開。

支援的服務：Outlook · Gmail · Google 行事曆 · Microsoft To Do · Todoist · TickTick · 開放標準。各帳號的連線方式和功能會分別列出。查看各服務說明。

用 AI 代理設定檢查信箱是否支援

登入在瀏覽器或作業系統鑰匙圈中完成，AI 代理拿不到 Corresync 管理的憑證，也沒有託管中繼伺服器。重要寫入會先顯示預覽，你核准後才執行。

設定 Corresync

使用本機代理安裝或更新 Corresync，並安裝隨附的 Agent Skill。每項變更由你確認和核准。

建議使用獨立版 CLI。新安裝會啟用經過驗證的自動更新。如果已經安裝過，會沿用原本的套件管理工具、設定和更新選項，除非你自己變更。

用 Codex 設定 用 Claude Code 設定

快速開始

安裝後的三個步驟

Corresync 不會預選服務。它先不用憑證查出位址可用的連線方式，加入你選的那一種，之後才能登入這個帳號。

1 · 選擇並登入

corr setup you@example.com --alias personal
corr auth login --account personal

查詢時不會開啟任何頁面。另外執行的 login 只使用選定的連線方式。

2 · 連接 AI 代理

corr integrations setup codex

把本機 stdio 伺服器註冊到 AI 代理，然後重新啟動用戶端一次。

3 · 提問

› 彙總所有帳號裡今天中午前
  需要我處理的事情

AI 代理呼叫工具，回答會標明每筆資訊來自哪個帳號。

使用範例

一次查詢多個收件匣和行事曆

CLI 和 MCP 使用相同的操作、帳號隔離和政策檢查。

同時搜尋所有收件匣

「找出季度計畫的郵件，我忘了是在工作還是個人信箱。」 

$ corr mail search --all-accounts \
    --query 'subject:"quarterly plan"'
● work · microsoft-owa  Ana Ruiz  Plan review
· personal · jmap   Finance      Plan receipt

如果某個帳號查詢失敗，結果會標示為不完整，不會直接略過。

查看合併後的行程

「工作和個人行事曆裡，今天有哪些行程？」

$ corr agenda list --all-accounts \
    --start 2026-07-29T00:00:00Z \
    --end 2026-07-30T00:00:00Z
09:30 work      Design review · Teams
12:30 personal  Dentist

每個活動都會保留時區、所屬行事曆和服務來源。

傳送前先預覽

「幫我草擬給 Ana 的回覆，要不要傳送由我決定。」 

› 起草給 Ana 的回覆
  mail_send
REVIEW · send new message
  to    ana@example.invalid
  body  text/plain · 412 B
確認這份內容之前不會傳送。

實際送出的帳號、收件人和內容必須與預覽時完全一致。

安全

第一次呼叫只會回傳預覽

重要操作會先回傳預覽。核准只對同一呼叫者、帳號、服務、目標和內容有效，有期限且只能用一次。

  • AI 代理只能使用 Corresync 提供的工具。密碼、Cookie 和 OAuth 授權不會經過 MCP，設定檔中也沒有對應欄位。
  • 只在本機執行。MCP 伺服器在你的電腦上透過 stdio 通訊，不使用遠端端點。
  • 結果不明時就停止。無法確定遠端寫入是否成功時，不會自動重試。
  • 郵件內容一律視為不可信資料。郵件中的文字不能用來執行指令或啟動 AI 代理。

連線方式

服務原生 API 與開放標準

郵件和行事曆的連線方式分開選擇，所以同一個帳號可以用 IMAP/SMTP 收發郵件，再用 CalDAV 存取行事曆。

瀏覽器登入

Outlook Web

Outlook 的互動式登入在專用的瀏覽器視窗中進行，郵件和行事曆操作都可以使用。

OAuth

Microsoft Graph · Google 使用你自己的用戶端

Graph 使用你有權使用的公開用戶端。Google 使用你自己的桌面版 OAuth 用戶端。

開放標準

JMAP、IMAP/SMTP、CalDAV

使用加密端點，憑證放在作業系統鑰匙圈或經你核准的輔助程式。

限制

目前的限制

完整的功能、限制和驗證範圍請見功能頁面。

  • Gmail、Google 行事曆和 Google Tasks 可使用你自己的 OAuth 用戶端。 引導式設定會先把桌面用戶端憑證匯入作業系統鑰匙圈，之後再由你登入。
  • Microsoft Graph 需要自備 OAuth 用戶端。Corresync 不提供權杖中繼服務。
  • Windows 目前沒有桌面通知。佇列和已核准的執行器仍可使用。
  • 可用功能依帳號而定。 設定時會顯示這個帳號實際的連線方式和服務，不會只看信箱品牌推測。
