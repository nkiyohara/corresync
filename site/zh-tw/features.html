功能

所有能做的事，以及絕不越過的邊界。

跨收件匣和行事曆讀取時仍保留帳號身分；每次寫入只針對一個明確帳號。CLI 與 MCP 共用同一型別化操作、策略檢查和預覽→提交。

四步開始檢查支援服務

日常通訊

統一處理郵件和行事曆，不合併身分。

01

郵件

  • 資料夾、標籤與能力發現
  • 有上限的列表、搜尋與 thread 搜尋
  • 按需讀取 header、內文和有上限的附件
  • 建立和更新草稿、回覆、轉發與傳送
  • 已讀/未讀、歸檔、移動與垃圾箱
  • 跨帳號搜尋與明確的部分失敗

傳送、移動和刪除先回傳審閱，只有完全一致的內容才能提交一次。

02

行事曆與日程

  • 明確選擇可用行事曆
  • 有上限的事件列表與跨帳號日程
  • 保留時區和重複規則
  • 建立、更新與取消事件
  • 路徑報告支援時才請求 Teams 或 Google Meet
  • 會議連結僅作為單個事件的屬性

目前版本尚未啟用 Teams 聊天與頻道。實作已置於發行證據閘門之後；通話、錄製、上線狀態監控與會議生命週期管理仍不在範圍內。

同一核心，兩種入口

AI 智慧體與指令碼遵守同一安全邊界。

03

AI 智慧體 · 本機 stdio

  • 只提供狹窄、型別化的郵件和行事曆工具
  • 不暴露認證資料、Cookie、任意 action 或通用 property API
  • 讀取與寫入預覽／提交明確分開
  • 結果保留帳號和供應商來源
  • 不建立 遠端 MCP 端點
corr mcp setup codex

04

指令碼 · 穩定 JSON

  • 人類輸出與機器 JSON 分離
  • 使用同一帳號選擇和策略檢查
  • 不隱藏部分失敗、降級或未知結果
  • stdout 輸出資料，stderr 輸出診斷
  • schema 遵循公開版本策略
corr agenda list --all-accounts --format json

主動開啟的本機能力

只在需要時，由你親自開啟。

只讀匯入暫存

掃描其他應用設定並顯示候選，不復用 機密資訊，不新增帳號，也不認證。

選擇性監控

預設關閉。只有明確設定帳號、查詢、間隔和目標後才在本機執行；MCP 無法啟用。

隱私保護意見回饋

絕不自動傳送。欄位先供你審閱，且不包含郵件內容、位址、權杖 或認證資料。

已驗證更新

驗證簽名 checksum 與 來源證明；包管理器安裝仍由對應管理器更新。

安裝前常見問題

先把重要問題說清楚。

我的帳號能用嗎？

支援 Outlook Web、明確設定的 Graph、Todoist、TickTick、JMAP、IMAP/SMTP 和 CalDAV。Google 路徑使用你自行管理的 Google Cloud 專案中的桌面 OAuth 用戶端。可只用網域檢查。

需要付費嗎？

Corresync 是 Apache-2.0 開源軟體；供應商、雲、智慧體和網路費用遵循各自條款。

郵件存在哪裡？

資料從裝置直接連線供應商，沒有 Corresync 託管信箱或權杖 中繼服務。本機快取和游標依帳號隔離。

AI 能自行傳送嗎？

不能。第一次呼叫只回傳審閱，提交需要與內容繫結、短時、單次的核准。

會偷偷聯網嗎？

沒有 analytics 或 telemetry。只有目的明確的可選 相容性檢查工具、更新檢查、所選供應商操作與意見回饋。

傳送中途結果不明怎麼辦？

不會自動重試；會停在“結果未知”，要求核對，避免重複傳送。

明確不做

不以便利為名擴大權限。

  • 託管中繼服務、多使用者伺服器、遠端 MCP 傳輸
  • 無人值守登入、儲存密碼、TLS 攔截
  • 繞過 MFA、Conditional Access、管理員同意或停用服務
  • 自動 替代路徑 到 Graph 或自動能力探測
  • 目前版本中的 Teams 聊天與頻道功能
  • Teams 通話、錄製、上線狀態監控與會議生命週期管理
  • 把郵件內容當成授權或指令
  • 預設開啟監控、智慧體派發或資料外傳
  • Gmail 即時永久刪除

相容性證據

合成測試不等於即時供應商驗證。

開發路徑使用確定性的合成測試資料契約。只有記錄了 opt-in、合成資料、確切 提交 與環境的觀測，才會標記為 live-observed。

supported：已發布的執行檔中可以使用。

synthetic contract：使用模擬 服務供應商契約 的 測試資料 驗證。

live-observed：存在明確記錄的可選即時觀測。

degraded：能力缺失會被如實回傳。
