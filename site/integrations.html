Labels

What the labels mean

Published

Published

A public record was checked at the version shown. The stable release automation must check it again after publishing.

Source available

Source available

A versioned native package is built and tested in this repository. We do not claim a listing in the vendor’s official directory.

Not listed

Not listed

Use corr setup to add Corresync directly as an MCP server. Marketplace submission waits for native metadata and the vendor’s review.

Local only

A listing does not enable hosted agents or tunnels

Corresync runs one local stdio server and keeps account state on your computer. Hosted ChatGPT, cloud agents, Kiro Web, and remote sandboxes cannot reach it just because a plugin format exists for them.

A hosted relay or private MCP tunnel would add a new path for your data. It would need its own architecture decision, consent, privacy disclosure, revocation design, and security review.
