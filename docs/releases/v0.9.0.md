# Corresync 0.9.0

## What's Changed

Corresync 0.9.0 is now stable. Development and future releases continue on
`main`; the 0.8 maintenance line is closed. Upgrade both local and remote
installations before using the SSH login helper.

- **Remote graphical Outlook Web login:** run
  `corr auth login --host HOST --account ALIAS` on your Mac/local computer, or
  run `corr auth login --account ALIAS --web` remotely and follow its explicitly
  labeled local SSH instructions. The temporary screen is private, loopback-only,
  and expires; the authenticated account remains on the remote host.
  [Connection guide](https://github.com/nkiyohara/corresync/blob/v0.9.0/docs/remote-login.md).
- **Per-account service switches:** Settings → Accounts → account → Services
  provides checkboxes for configured Mail, Calendar, To Do / Tasks, and
  Teams / Messaging. All configured services default to on. Disabling retains
  connection settings and blocks authentication and operations. Changes stop
  existing sessions and invalidate pending approvals; reauthenticate explicitly.
- **Messaging previews enabled:** Teams Graph, Teams Web, and Mattermost can now
  be selected and used with the existing bounded contracts and approval checks.
  Slack remains excluded; use the provider's existing connectors.
- **Outlook attachment fixes:** batch attachments use the final draft change key
  and reject inconsistent parent identities before sending. Saved-draft sending
  and attachment handling also include the fixes shipped during the RC series.
- **Authentication and platform improvements:** includes the chromedp migration,
  user-owned Google OAuth, setup and diagnostics improvements, and the Go 1.26.10
  security baseline developed and verified during 0.9 prereleases.

## Compatibility and upgrade notes

Teams Graph, Teams Web, and Mattermost are **preview features with incomplete
live verification**, even though the product version is stable. This release
does not invent or complete missing provider evidence. The remote graphical login
flow also remains unobserved with a real Mac-to-Linux provider account; its
transport and browser contracts use synthetic tests. It currently supports
Outlook Web, not the separate Teams Web browser. Platform passkeys, USB keys,
client certificates, and provider device policy are not forwarded or bypassed.

Configuration v11 migrates to v12 without changing existing service selections.
Older binaries refuse the new schema. Private daemon protocol v27 replaces the
previous owner through the normal lifecycle; restart consuming MCP hosts after
updating. Explicit provider selection, consent, account isolation, and write
preview/commit safeguards remain in force.
