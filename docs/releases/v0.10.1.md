# Corresync 0.10.1

## Assisted first sign-in

An agent can request the first sign-in for an account, including after a
connection change. After accepting the MCP prompt, check the account and each
destination in the Corresync dialog on the host. Authentication stays in the
provider UI. Hosts without a supported local dialog offer the manual CLI
command. The daemon records verification after successful authentication.
The private daemon protocol is now 34.

## Installed Skills

After upgrading, an interactive CLI command offers to refresh older managed
Skills for the user and the current project. Review the host and scope before
applying. The new binary supplies its own version of the Skill. Local edits
are protected, and a declined offer stays dismissed for that version and
target. Start a new host session or reload after applying. To check or retry
manually, use `corr integrations doctor` and `corr integrations repair HOST`
with the appropriate scope.

These changes have synthetic coverage. No new live provider observation is
claimed.
